  <name>Task 1: Install workspace deps and run TypeScript check</name>
  <files></files>

  <read_first>
    - apps/showcase/package.json — verify voltventure-design-system workspace:* is present
    - package.json (root) — verify workspaces: ["apps/*"] is present
  </read_first>

  <action>
    From the design system root (6. Design System/), run `npm install`. This installs all workspace dependencies and creates the workspace symlink: node_modules/voltventure-design-system → the design system root.

    If npm install fails with "workspace:* not supported": check npm version with `npm --version`. If npm < 7, the workspace:* protocol is not supported. In that case, update the showcase's package.json to use `"voltventure-design-system": "*"` and add an `.npmrc` file in the design system root with content `workspaces-update=true`. Then re-run `npm install`.

    After npm install succeeds, from apps/showcase/ run `npx tsc --noEmit`. Capture the full output. If it exits 0, proceed. If it fails:
    - "Cannot find module 'voltventure-design-system'" → the workspace symlink was not created; verify paths field in tsconfig.json
    - "Type errors in registry.ts" → a Preview file has incorrect export names; read the failing file and fix the import
    - Any other error → report the full error message in the SUMMARY

    After TypeScript passes, from apps/showcase/ run `npx expo start --no-dev` and capture the Metro startup output. The server starts successfully when Metro prints "Metro waiting on exp://..." or "Starting Metro Bundler". If Metro prints "Unable to resolve module", capture the full module name and report in SUMMARY.
  </action>

  <verify>
    <automated>cd "apps/showcase" && npx tsc --noEmit 2>&1 | tail -5</automated>
  </verify>
