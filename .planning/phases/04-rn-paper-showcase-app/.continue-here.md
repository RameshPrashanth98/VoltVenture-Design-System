## Critical Anti-Patterns (do NOT repeat these)
- **Metro ENOENT on `.bottom-tabs-*`**: Windows npm leaves temp extraction dirs; Metro file watcher registers them and crashes when dir is cleaned up. Always use `npx expo start --clear` to reset watcher state.
- **git stash + new files**: Staging new files then stashing causes them to be lost if stash pop fails. Instead: commit or use a temp branch for new files before any git pull/merge operations.
