- [ ] CONSTRAINT: Windows-worktree-bleed — Worktree agent writes bleed through to the main working tree on Windows, causing merge conflicts. Structural mitigation: on merge conflict, run `git restore <file>` to discard the bleed, then `git checkout <worktree-branch> -- <file>` to take the worktree version. Never attempt the merge on a dirty tree.

**Do not proceed until all boxes are checked.**

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Windows worktree bleed | On Windows, worktree agents write files (package.json, .gitignore, etc.) visible in the main tree before merge, causing `git merge` to fail with "Your local changes would be overwritten". Manifested during Wave 1 cleanup. | advisory | Before each worktree merge: run `git status --short`. If conflicted files appear as modified, run `git restore <file>` to discard the local bleed, then proceed with merge. Take the worktree version for package.json/package-lock.json conflicts. |
| Storybook version mismatch | Phase description says "Storybook 8" but npm installs v10. Addon-essentials is empty in SB10. | advisory | Always install `storybook@latest` (resolves to 10.x). Never add @storybook/addon-essentials. The `addons: []` array in main.js is correct and complete. |

## Critical Token Facts for Story Executors

- Import: `import * as tokens from '../generated/tokens.js'` (from stories/ directory, relative path)
- All story named exports MUST be PascalCase: `export const Palette`, not `export const palette`
- Shadow format: `elevationRaised = { color: "#0F0F0F0F", offsetX: 0, offsetY: 2, blur: 8, spread: 0 }` — 8-char RRGGBBAA hex needs inline hexToRgba() conversion
- Typography: `typeDisplayXl = { fontFamily: "Manjari", fontSize: 40, fontWeight: 700, lineHeight: 42, letterSpacing: 0 }` — append "px" to fontSize and lineHeight for CSS
- typeOverline: add `text-transform: uppercase; letter-spacing: 0.12em`
- typeNumericLg, typeNumericMd: add `font-variant-numeric: tabular-nums`
- elevationFlat.color is the string `"none"` (not an object) — check with strict equality
