  <name>Task 2: Write .storybook/main.js (ESM config) and preview-head.html (Google Fonts)</name>
  <files>.storybook/main.js, .storybook/preview-head.html, .gitignore</files>

  <read_first>
  - .planning/phases/02-storybook-documentation/02-RESEARCH.md — Pattern 1 (main.js), Pattern 5 (preview-head.html), Anti-Patterns section
  - .planning/phases/02-storybook-documentation/02-CONTEXT.md — D-01 (framework), D-02 (glob), D-05 (fonts)
  - .gitignore — current contents before modification
  </read_first>

  <action>
  Create the .storybook/ directory and write two files.

  File 1 — .storybook/main.js:
  Must be valid ESM (no require(), no module.exports, no __dirname). The file uses export default. Set framework to '@storybook/html-vite'. Set stories glob to '../stories/**/*.stories.js' (relative to .storybook/, resolves to project-root/stories/). Set addons to an empty array — Storybook 10 essentials are built-in, no @storybook/addon-essentials entry needed.

  Include a JSDoc type annotation line: /** @type {import('@storybook/html-vite').StorybookConfig} */ above the const config declaration. This enables IDE type hints.

  File 2 — .storybook/preview-head.html:
  Inject Google Fonts CDN links for the three VoltVenture fonts — Manjari (weights 100;400;700), Inter (opsz 14..32, weights 400..700, italic variants), and JetBrains Mono (weights 400;500). Include a preconnect link for fonts.googleapis.com and fonts.gstatic.com (with crossorigin attribute). Include the stylesheet link with display=swap. This file only affects the preview iframe, not the Storybook manager chrome.

  Also update .gitignore: add storybook-static/ on its own line if it is not already present. storybook-static/ is the default output directory for "storybook build" and should not be committed.

  Verify ESM validity of main.js by running: node --input-type=module < .storybook/main.js
  (This parses the file as ESM and prints any syntax errors. It will exit non-zero and print an error if require() or module.exports is present.)
  </action>

  <verify>
    <automated>node --input-type=module < .storybook/main.js && grep -q "export default" .storybook/main.js && grep -q "html-vite" .storybook/main.js && grep -q "stories/\*\*/\*\.stories\.js" .storybook/main.js && grep -q "fonts.googleapis.com" .storybook/preview-head.html && grep -q "Manjari" .storybook/preview-head.html && grep -q "storybook-static" .gitignore && echo "ALL OK"</automated>
  </verify>
