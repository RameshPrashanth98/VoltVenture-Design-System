  <action>
  Create stories/typography.stories.js as a plain ES module.

  Structure:
  - Import: import * as tokens from '../generated/tokens.js'
  - Default export: { title: 'Foundation/Typography' }
  - One named story export: TypeScale (PascalCase)

  Define a specimen helper function (not exported). It takes (tokenName, t, copy, extra) where:
  - t is the composite token object {fontFamily, fontSize, fontWeight, lineHeight, letterSpacing}
  - copy is the VoltVenture specimen string
  - extra is an optional CSS string for special cases (e.g. 'text-transform:uppercase' or 'font-variant-numeric:tabular-nums')

  The helper returns a grid row with three columns (grid-template-columns: 160px 1fr 220px):
  - Column 1: token name in Inter 11px 600 #808080
  - Column 2: the rendered text specimen using CSS derived from the composite (font-family from t.fontFamily quoted, font-size t.fontSize+"px", font-weight t.fontWeight, line-height t.lineHeight+"px", letter-spacing t.letterSpacing+"em", color:#0f0f0f) plus any extra CSS
  - Column 3: metadata in JetBrains Mono 10px #808080 showing: fontSize+"px / "+lineHeight+"px / "+fontWeight, fontFamily on a second line

  The TypeScale story renders a container with padding:32px, background:#ffffff, and renders all 14 specimens in order using the specimen helper. The specimens and their copy strings:
  - typeDisplayXl: "Good morning, Arjun"
  - typeDisplayLg: "Nearby Drivers"
  - typeDisplayMd: "Trip History" (typeDisplayMd exists in tokens.js — include it)
  - typeNumericLg: "1,247" — extra: 'font-variant-numeric:tabular-nums'
  - typeNumericMd: "₹ 248.00" — extra: 'font-variant-numeric:tabular-nums'
  - typeHeadingLg: "My Rewards"
  - typeHeadingMd: "Booking Summary"
  - typeHeadingSm: "Payment Method"
  - typeBodyLg: "Your driver is 2 minutes away"
  - typeBodyMd: "Estimated arrival in 4 minutes"
  - typeBodySm: "Last updated 3 minutes ago"
  - typeLabelMd: "Confirm Ride"
  - typeLabelSm: "Cancel"
  - typeOverline: "SAFETY STATUS" — extra: 'text-transform:uppercase'

  For typeOverline, the letterSpacing value in the token is 0.12 — this maps to letter-spacing:0.12em in CSS. The extra parameter adds text-transform:uppercase per D-06 and PROJECT.md spec.

  Separate each specimen row with a 1px solid #ebebeb bottom border. Add a column header row above the specimen rows with headings "Token", "Specimen", "Metrics".
  </action>
