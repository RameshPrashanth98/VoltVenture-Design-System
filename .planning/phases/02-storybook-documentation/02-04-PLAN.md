  - Import: import * as tokens from '../generated/tokens.js'

  - One named export: ElevationScale (PascalCase)

  Define hexToRgba as a non-exported function with this exact logic:
  Takes hex8 string (e.g. "#0F0F0F1A"). Extracts r = parseInt(hex8.slice(1,3),16), g = parseInt(hex8.slice(3,5),16), b = parseInt(hex8.slice(5,7),16), a = (parseInt(hex8.slice(7,9),16)/255).toFixed(2). Returns "rgba("+r+", "+g+", "+b+", "+a+")".

  Define shadowFromToken as a non-exported function. Takes a token value (either the string "none" or an elevation object). If the token === 'none' (strictly equals the string, not falsy check — elevationFlat is the literal string "none"), return 'none'. Otherwise build the CSS box-shadow string: token.offsetX+"px "+token.offsetY+"px "+token.blur+"px "+token.spread+"px "+hexToRgba(token.color).

  The ElevationScale story renders a flex row (flex-wrap:wrap, gap:32px) on a #f5f5f5 background with padding:48px. Each of the 4 elevation levels is a card:
  - Card container: 160px wide, 120px height, background:#ffffff, border-radius:12px, padding:16px, box-shadow set via shadowFromToken(tokens.elevationXxx)
  - Card label line 1: elevation token name in Inter 13px 600 #0f0f0f
  - Card label line 2: the CSS box-shadow value string (or "none") in JetBrains Mono 10px #808080, word-break:break-all

  Four cards in order: elevationFlat, elevationRaised, elevationFloating, elevationOverlay.
  </action>
