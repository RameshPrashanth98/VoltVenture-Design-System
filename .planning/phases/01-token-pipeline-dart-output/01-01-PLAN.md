<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| package.json → npm registry | npm install fetches packages from the internet; malicious packages could execute in postinstall hooks |
| style-dictionary.config.mjs → tokens/ | SD reads JSON files from the local filesystem; malformed JSON causes parse errors but not security issues |
| SD build → lib/ write | SD writes to lib/ on disk; the only concern is accidental overwrite of hand-edited files |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-01-01 | Tampering | npm install (package resolution) | mitigate | Pin exact SD v4 version; verify package.json devDependencies match expected packages before install |
| T-01-02 | Tampering | generated lib/*.dart files | mitigate | Add "AUTO-GENERATED — DO NOT EDIT" header comment in every generated file; Plan 06 adds CI diff check |
