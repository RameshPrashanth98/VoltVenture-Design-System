<objective>
Generate lib/voltventure_theme.dart — the Flutter ThemeData factory that wires token constants into Flutter's theming API. This file uses ColorScheme.fromSeed() to safely populate all required ColorScheme fields, then overrides with explicit semantic tokens via copyWith(). All 14 type styles are emitted using the GoogleFonts method API.

Purpose: The ThemeData factory is the integration point between the token system and the Flutter app. It enables `MaterialApp(theme: voltVentureTheme())` to apply the entire token system in a single call. The fromSeed() strategy (D-07) prevents the Pitfall F2 (missing ColorScheme required fields) without placeholder values.

Output: lib/voltventure_theme.dart, sd-transforms/dart-theme.format.mjs, and an updated style-dictionary.config.mjs wiring the dart/theme platform.
</objective>

<!-- TextTheme slot mapping (Material 3 → spec style): -->
<!-- displayLarge  → display.xl  (40pt Manjari 700) -->
<!-- displayMedium → display.lg  (32pt Manjari 700) -->
<!-- displaySmall  → display.md  (28pt Manjari 700) -->
<!-- headlineLarge → numeric.lg  (28pt Inter 700 tabular) -->
<!-- headlineMedium→ numeric.md  (22pt Inter 700 tabular) -->
<!-- titleLarge    → heading.lg  (20pt Inter 600) -->
<!-- titleMedium   → heading.md  (17pt Inter 600) -->
<!-- titleSmall    → heading.sm  (15pt Inter 600) -->
<!-- bodyLarge     → body.lg     (17pt Inter 400) -->
<!-- bodyMedium    → body.md     (15pt Inter 400) -->
<!-- bodySmall     → body.sm     (13pt Inter 400) -->
<!-- labelLarge    → label.md    (13pt Inter 600) -->
<!-- labelMedium   → label.sm    (11pt Inter 500) -->
<!-- labelSmall    → overline    (10pt Inter 500, +tracking) -->

<!-- LineHeight formula: height = lineHeight_pt / fontSize_pt -->
<!-- display.xl: 42/40 = 1.05 -->
<!-- display.lg: 36/32 = 1.125 -->
<!-- display.md: 32/28 = 1.143 (rounded) -->
<!-- numeric.lg: 30/28 = 1.071 (rounded) -->
<!-- numeric.md: 26/22 = 1.182 (rounded) -->
<!-- heading.lg: 26/20 = 1.3 -->
<!-- heading.md: 24/17 = 1.412 (rounded) -->
<!-- heading.sm: 20/15 = 1.333 -->
<!-- body.lg: 26/17 = 1.529 (rounded) -->
<!-- body.md: 22/15 = 1.467 -->
<!-- body.sm: 18/13 = 1.385 (rounded) -->
<!-- label.md: 16/13 = 1.231 (rounded) -->
<!-- label.sm: 14/11 = 1.273 (rounded) -->
<!-- overline: 14/10 = 1.4 -->

<!-- letterSpacing: Flutter uses absolute logical pixels, not em. Multiply em value by fontSize: -->
<!-- numeric.lg: -0.02em × 28pt = -0.56 -->
<!-- numeric.md: -0.02em × 22pt = -0.44 -->
<!-- heading.lg: -0.01em × 20pt = -0.20 -->
<!-- overline: 0.12em × 10pt = 1.2 -->
