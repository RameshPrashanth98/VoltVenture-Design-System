# BLOCKING CONSTRAINTS — Read Before Anything Else

> These are not suggestions. Each constraint below was discovered through previous sessions.
> Acknowledge each one explicitly before proceeding.

- [ ] CONSTRAINT: SD v4 DTCG `$value` — In SD v4 with `usesDtcg: true`, use `token.$value` (NOT `token.value`). Transforms store results back in `token.$value`. Any formatter reading `token.value` will get `undefined`.
- [ ] CONSTRAINT: Formatter filter required — Transforms without a `filter` run on ALL tokens. For the `rn/theme` platform, the formatter emits static code (not token-driven), so a filter selecting just one representative token (e.g. semantic color) prevents corrupting the transform chain.
- [ ] CONSTRAINT: Platform is React Native Paper (2026-07-25) — No Dart/Flutter tools. `dart analyze` is NOT the done-bar. `tsc --noEmit` is. Do not reference Dart output in Plan 07 execution.

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| SD transform without filter | A transform that runs on ALL tokens corrupts every non-matching token | blocking | Every custom transform MUST have a `filter` function that returns true only for the target `$type` |
| Reading `token.value` in SD v4 | `token.value` is undefined in `usesDtcg: true` mode | blocking | Always read `token.$value`; write back to `token.$value` in transforms |

<context>
The TS constants formatter is simpler than the Dart formatter — no ARGB conversion, no `double` type suffix, no `BoxShadow` class. Colors are hex strings, dimensions are plain numbers, shadows are RN prop objects. The RN Paper theme formatter is a static emitter: it does not iterate dictionary tokens — it emits hardcoded TS code that references the camelCase token export names from `voltventure_tokens.ts`.

The MD3LightTheme spread strategy means we never need to specify every MD3 color role explicitly — just the ones where we have explicit semantic tokens (primary, onPrimary, secondary, onSecondary, surface, background, onSurface, outline). All other roles inherit from MD3LightTheme defaults.
</context>
