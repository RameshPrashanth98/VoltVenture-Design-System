<objective>
Implement all build-time validators that enforce the three non-negotiable constraints: accessibility (WCAG AA contrast), brand integrity (electric green as background only), and design system consistency (4pt grid alignment). All validators are build-breaking — the pipeline must not exit 0 if any constraint is violated.

Purpose: These validators are the automated guard rails that make the token system self-defending. Without them, a single bad value change (e.g., moving color.text.accent to green.500 instead of green.700) could silently ship 1.36:1 contrast to production. The validators catch this at `npm run build:validate` before any code is generated.

Output: scripts/validate-tokens.mjs (the validator harness), scripts/contrast-pairs.json (declarative WCAG pair config), and generated/contrast-report.md as a build artifact.
</objective>
