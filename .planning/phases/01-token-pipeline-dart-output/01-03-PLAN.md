DTCG JSON format (required — SD v4 uses $type/$value, never type/value):
```json
{ "color": { "green": { "500": { "$type": "color", "$value": "#C6FF2D", "$description": "Electric Green — primary brand accent" } } } }
```

Reference syntax (semantic tokens reference primitives like this):
```json
{ "$type": "color", "$value": "{color.green.500}" }
```

Primitive token values (from foundations spec — DO READ voltventure-foundations (1).html before authoring):

COLOR:
- color.black: #0F0F0F (Volt Black)
- color.white: #FFFFFF (Pure White)
- Grey ramp (9 steps): .050=#FAFAFA .100=#F5F5F5 .200=#EBEBEB .300=#C9C9C9 .500=#808080 .700=#4A4A4A .800=#2F2F2F .900=#1A1A1A .950=#0F0F0F
- Green ramp (5 steps): .100=#F4FFD9 .300=#DDFF7A .500=#C6FF2D .600=#A8DE1A .700=#7D9220

SPACING (11 steps, all multiples of 4, $type: dimension, values are numbers not strings):
- space.050: 2, space.100: 4, space.200: 8, space.300: 12, space.400: 16, space.500: 20, space.600: 24, space.800: 32, space.1000: 40, space.1200: 48, space.1600: 64

RADIUS (7 steps + full + squircle, $type: dimension):
- radius.xs: 8, radius.sm: 12, radius.md: 16, radius.lg: 20, radius.xl: 28, radius.2xl: 36, radius.full: 999
- radius.icon: 22.37 (squircle constant for app icon — proportional iOS continuous corner value; store as-is, document usage in $description)

TYPOGRAPHY (14 styles — format: size/lineHeight/weight/tracking):
- display.xl: 40/42/700/0 (Manjari)
- display.lg: 32/36/700/0 (Manjari)
- display.md: 28/32/700/0 (Manjari)
- numeric.lg: 28/30/700/-0.02em (Inter)
- numeric.md: 22/26/700/-0.02em (Inter)
- heading.lg: 20/26/600/-0.01em (Inter)
- heading.md: 17/24/600/0 (Inter)
- heading.sm: 15/20/600/0 (Inter)
- body.lg: 17/26/400/0 (Inter)
- body.md: 15/22/400/0 (Inter)
- body.sm: 13/18/400/0 (Inter)
- label.md: 13/16/600/0 (Inter)
- label.sm: 11/14/500/0 (Inter)
- overline: 10/14/500/0.12em (Inter, uppercase)
Store sizes/lineHeights as raw numbers (not strings). Tracking in em is stored as a number (0.12 not "0.12em") with $description noting the unit.

ELEVATION (4 levels, $type: shadow):
- elevation.flat: none (store as empty string or omit shadow, $type: shadow, $value: "none")
- elevation.raised: color #0F0F0F1F (that is 12% opacity), offsetX 0, offsetY 2, blur 8, spread 0
- elevation.floating: color #0F0F0F1A (10% opacity), offsetX 0, offsetY 8, blur 24, spread 0
- elevation.overlay: color #0F0F0F29 (16% opacity), offsetX 0, offsetY 16, blur 48, spread 0
Shadow hex computation: rgba(15,15,15,0.06) → 0.06×255 ≈ 15 → 0F → #0F0F0F0F. rgba(15,15,15,0.10) → 26 → 1A → #0F0F0F1A. rgba(15,15,15,0.16) → 41 → 29 → #0F0F0F29. The spec shows .06/.10/.16 opacity. NOTE: the spec HTML shows "rgba(15,15,15,.06)" which is 6% = hex 0F. Raised=0F, Floating=1A, Overlay=29.

BORDER ($type: dimension):
- border.width.none: 0
- border.width.hairline: 1
- border.width.strong: 1.5
- border.width.focus: 2

GRID (all $type: dimension except columns which is a unitless number):
- grid.columns: 4 (no $type — store as number without $type)
- grid.margin: 16
- grid.gutter: 16
- grid.contentWidth: 361

ICONOGRAPHY ($type: dimension):
- icon.canvas: 24
- icon.liveArea: 20
- icon.padding: 2
- icon.size.xs: 16
- icon.size.sm: 20
