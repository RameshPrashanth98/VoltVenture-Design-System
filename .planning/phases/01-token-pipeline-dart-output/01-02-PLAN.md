SD v4 transform registration:
```javascript
// Each transform module exports a transform config object:
export const colorFlutterTransform = {
  name: 'voltventure/color/flutter',
  type: 'value',            // operates on token values
  filter: (token) => token.$type === 'color',  // SD v4: filter not matcher
  transform: (token) => { /* return string like Color(0xFFC6FF2D) */ }
};
```

SD v4 requires transforms to be registered before building:
```javascript
import StyleDictionary from 'style-dictionary';
import { colorFlutterTransform } from './sd-transforms/color.flutter.mjs';
StyleDictionary.registerTransform(colorFlutterTransform);
```

Unit test structure (Node.js built-in test runner):
```javascript
import { test } from 'node:test';
import assert from 'node:assert/strict';
import { colorFlutterTransform } from '../color.flutter.mjs';
```

Type conversion rules (from RESEARCH.md Q2):
- Color: strip '#', prepend 'FF', format as Color(0xFFRRGGBB). Input: '#C6FF2D' → 'Color(0xFFC6FF2D)'
- Dimension: parse numeric value (strip 'pt' suffix if present), emit as N.0 (always double). Input: 16 or '16pt' → '16.0'
- Shadow: DTCG shadow object { color, offsetX, offsetY, blur, spread } → BoxShadow(color: Color(0xFFRRGGBB), offset: Offset(X, Y), blurRadius: B.0, spreadRadius: S.0). The shadow color '#0F0F0F1F' has 8-char hex including alpha — strip '#', use as-is (do NOT prepend FF when alpha is already present).
- LineHeight: takes the token's $value (absolute pt) AND requires the paired fontSize. Formula: height = lineHeight / fontSize. Input: { lineHeight: 20, fontSize: 16 } → 1.25 (Dart double emitted as '1.25').

Unit test assertions required per D-02:
- Color:      '#C6FF2D' → 'Color(0xFFC6FF2D)'
- Dimension:  16 → '16.0' and '16pt' → '16.0'
- Shadow:     {color:'#0F0F0F1F', offsetX:'0', offsetY:'2pt', blur:'8pt', spread:'0'} → "BoxShadow(color: Color(0x0F0F0F1F), offset: Offset(0.0, 2.0), blurRadius: 8.0, spreadRadius: 0.0)"
- LineHeight: { lineHeight: 20, fontSize: 16 } → '1.25'
