<!-- ProgressStrip interaction contract (from UI-SPEC.md + RESEARCH.md) -->

State: let step = 1  (1–4)

NOTE: UI-SPEC.md shows a min value of 0, but this plan implements min=1.
"Step 0 of 4" is not a valid UX state — the first step is always Step 1 of 4.
Back is disabled when step === 1 (the first real step). This is intentional and correct.

Strip: 4 horizontal segments in a row
  - Each segment: width calc(25% - gap), height 8px
  - Active segment (segmentIndex <= step): background tokens.colorActionPrimary (#c6ff2d)
  - Inactive segment: background rgba(255,255,255,0.20)  [/* #FFFFFF33 — no token */]
  - Note: The existing strip() function has 2 segments — the Interactive export builds 4 independently

ProgressStrip background: tokens.colorGrey900 (#1a1a1a)
Border-radius for the strip container: tokens.radiusXs (8)px per segment

Step label: "Step {step} of 4" — Inter 15px 600

Next button:
  label: "Next →"
  bg: tokens.colorActionPrimary (#c6ff2d) when enabled
  opacity: 0.4, cursor: default when disabled (step === 4)
  on click: step = Math.min(step + 1, 4); update all 4 segment backgrounds; update label; update button disabled state

Back button:
  label: "← Back"
  bg: tokens.colorGrey200 (#ebebeb) or white border
  opacity: 0.4, cursor: default when disabled (step === 1)
  on click: step = Math.max(step - 1, 1); update segments; update label; update button states

State update strategy:
  Maintain references to all 4 segment divs and both button elements.
  On each step change, loop over segments and set .style.background directly.
  Update stepLabel.textContent.
  Update nextBtn and backBtn .style.opacity and .style.cursor.
  DO NOT rebuild innerHTML on state change.

<!-- MapPin interaction contract (from UI-SPEC.md + RESEARCH.md) -->

MapPin display: two pins over a mock map background div (#e8e8e8, flex:1, position:relative)

RangePin:
  - Circular pin, background tokens.colorGrey900 (#1a1a1a), 48px × 48px, border-radius 50%
  - Not interactive — static

SelectedPin:
  - Background tokens.colorActionPrimary (#c6ff2d), 48px × 48px, border-radius 50%
  - Has a pulse ring div (child): 48px × 48px, border-radius 50%, background rgba(198,255,45,0.20)
    [/* colorActionPrimary at 20% — no token */]
  - On click: trigger pulse animation on the pulse ring

@keyframes vv-pulse injection (idempotency guard):
  if (!document.getElementById('vv-pulse-kf')) {
    const s = document.createElement('style');
    s.id = 'vv-pulse-kf';
    s.textContent = '@keyframes vv-pulse { 0% { transform:scale(1); opacity:1; } 50% { transform:scale(1.4); opacity:0.6; } 100% { transform:scale(1); opacity:0; } }';
    document.head.appendChild(s);
  }

Animation restart pattern (critical — see RESEARCH.md Pitfall 6):
  selectedPin.addEventListener('click', () => {
    pulseRing.style.animation = 'none';
    void pulseRing.offsetWidth;  // force reflow to restart animation
    pulseRing.style.animation = 'vv-pulse 600ms ease forwards';
    setTimeout(() => { pulseRing.style.animation = 'none'; }, 620);
  });
