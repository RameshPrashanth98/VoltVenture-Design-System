<!-- PhoneInput interaction contract (UI-SPEC.md) -->
State:
  focused: false (initial)
  digits: '' (initial, max 10 chars, digits only)

Display format: "+1 (___) ___-____" when empty
  digits filled: "+1 (NNN) NNN-NNNN" with digits replacing underscores left-to-right
  (Simple fill: display first 3 digits in (___), next 3 in ___-, last 4 in ____)

Focus event (click on visible display):
  → call hiddenInput.focus()
  → focused = true
  → displayDiv.style.borderColor = tokens.colorBorderFocus  (#c6ff2d)
  → displayDiv.style.border = '2px solid #c6ff2d'
  → show blinking cursor span: cursor.style.display = 'inline'

Input event on hiddenInput:
  → filter to digits only (hiddenInput.value.replace(/\D/g,'').slice(0,10))
  → digits = filtered value
  → update the phone number display span text content
  → if focused, cursor stays visible

Blur event on hiddenInput:
  → focused = false
  → displayDiv.style.border = '2px solid transparent' (or tokens.colorGrey200 #ebebeb)
  → cursor.style.display = 'none'

Blinking cursor:
  → inject @keyframes vv-blink { 0%,100%{opacity:1} 50%{opacity:0} } once (idempotency guard: check document.getElementById('vv-blink-kf') before injecting)
  → cursor span: animation: vv-blink 1s infinite; width:2px; height:20px; background:#0f0f0f; display:none; vertical-align:middle; margin-left:2px

PhoneInput container:
  border-radius: tokens.radiusSm (12)px
  background: tokens.colorGrey050 (#fafafa)
  padding: 14px 16px
  font-size: tokens.typeBodyLg.fontSize (17)px
  font-family: Inter, sans-serif
  width: 100% of parent
  box-sizing: border-box

<!-- SegmentedToggle interaction contract -->
State:
  let active = 'phone'  (initial)

Tab container: background tokens.colorGrey100 (#f5f5f5), border-radius 999px, padding 4px
Two tab divs: 'Phone' and 'Email'
  active tab: background tokens.colorActionPrimary (#c6ff2d), color tokens.colorTextPrimary (#0f0f0f)
  inactive tab: background transparent, color tokens.colorTextSecondary (#808080)
  both: border-radius 999px, font-size 15px, font-weight 600, padding 10px 24px, cursor pointer

On click of either tab:
  → active = clicked tab name ('phone' or 'email')
  → mutate ONLY .style.background and .style.color on both tab divs
  → do NOT rebuild innerHTML (destroys listeners)
