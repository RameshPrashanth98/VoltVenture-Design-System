## Interaction Contracts (D-07)

All event handling via `addEventListener` on DOM elements (D-04). State held in plain JS variables (D-05). No `<script>` tags via innerHTML (D-06).

| Component | Event | State Change | DOM Update |
|-----------|-------|-------------|------------|
| Button (Primary) | `pointerdown` | pressed=true | bg → `#A8DE1A`, transform → `scale(0.97)` |
| Button (Primary) | `pointerup`, `pointerleave` | pressed=false | bg → `#C6FF2D`, transform → `scale(1)` |
| Button (Secondary) | `pointerdown` | pressed=true | bg → `#2F2F2F`, transform → `scale(0.97)` |
| Button (Secondary) | `pointerup`, `pointerleave` | pressed=false | bg → `#0F0F0F`, transform → `scale(1)` |
| Button (Ghost) | `pointerdown` | pressed=true | opacity → 0.6 |
| Button (Ghost) | `pointerup`, `pointerleave` | pressed=false | opacity → 1 |
| Button (Disabled) | — | no interaction | none |
| SocialAuthButtons | `pointerdown` on each | pressed=true | opacity → 0.7 on pressed button |
| SocialAuthButtons | `pointerup`, `pointerleave` | pressed=false | opacity → 1 |
| PhoneInput | `click` | focused=true | border → `2px solid #C6FF2D`, blinking cursor CSS |
| PhoneInput | typing (keydown) | number updates | update displayed phone number |
| SegmentedToggle | click Phone tab | active='phone' | Phone bg → `#C6FF2D`, Email bg → transparent |
| SegmentedToggle | click Email tab | active='email' | Email bg → `#C6FF2D`, Phone bg → transparent |
| ProgressStrip | click "Next" | step++ (max 4) | advance active step, disable Next at step 4 |
| ProgressStrip | click "Back" | step-- (min 0) | retreat active step, disable Back at step 0 |
| TrustPanel | — | static | none |
| StatusBar | — | static (top chrome) | none |
| OrDivider | — | static | none |
| MapPin | `click` | pulse=true | scale pulse animation (CSS keyframe), reset after 600ms |
| TabBar | click any tab | activeTab=N | update active tab indicator circle + label color |
| BottomCard | click drag handle | expanded=!expanded | height transition: collapsed (120px) → expanded (320px) |

### CSS Transition Defaults

| Interaction | Transition |
|-------------|-----------|
| Button press/release | `transform 100ms ease, background-color 100ms ease` |
| MapPin pulse | CSS `@keyframes` scale 1→1.4→1, 600ms, once |
| BottomCard expand/collapse | `height 300ms ease` |
| SocialAuthButton press | `opacity 100ms ease` |
| PhoneInput focus | `border-color 150ms ease` |
