# BLOCKING CONSTRAINTS — Read Before Anything Else

> These are not suggestions. Each constraint below was discovered through failure.
> Acknowledge each one explicitly before proceeding.

- [ ] CONSTRAINT: lib/ mutation — `npm run build:tokens` regenerates `lib/voltventure_theme.ts` and `lib/voltventure_tokens.ts` from SD templates, silently dropping the manual `onPrimary` override and changing `export const` → `const`. Run `git restore lib/voltventure_theme.ts lib/voltventure_tokens.ts` after every `build:tokens` call, before staging anything.

**Do not proceed until all boxes are checked.**

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| lib/ mutation on build:tokens | SD regenerates lib/ files on every build, losing manual overrides (onPrimary, export const). Manifested in Phase 5 every time done-bar ran. | blocking | After any `npm run build:tokens` or `npm run build-storybook`, run `git restore lib/voltventure_theme.ts lib/voltventure_tokens.ts` before `git add` |
| git add -A stages untracked files | .claire/ must never be committed — internal GSD worktree artifact | blocking | Always stage by explicit path only; never use git add -A or git add . |
