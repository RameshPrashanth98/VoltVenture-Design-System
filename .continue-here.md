## Critical Warnings

- **lib/ mutation**: `npm run build:tokens` regenerates `lib/voltventure_theme.ts` and `lib/voltventure_tokens.ts`, dropping manual overrides. Always run `git restore lib/voltventure_theme.ts lib/voltventure_tokens.ts` after any `build:tokens` call.
- **Story imports**: Use `../../generated/tokens.js` (explicit .js extension) from stories/screens/ or stories/components/
- **Interactive exports**: Must return DOM elements (not HTML strings)
